Lecture 4: Introduction to CSS

What is CSS?

CSS stands for Cascading Style Sheets. It is used to style HTML documents. While HTML provides the structure of a webpage, CSS controls its appearance including colors, fonts, layouts, spacing, borders, and responsive design.

JavaScript Logo

Advantages of CSS

  • Separates content from design
  • Makes websites look more attractive
  • Reduces repetition and keeps code organized
  • Improves website loading speed
  • Supports responsive design for different devices

Types of CSS

  1. Inline CSS – Applied directly to an element using the style attribute.
  2. Internal CSS – Defined within a <style> tag in the HTML document.
  3. External CSS – Written in a separate .css file and linked to HTML using <link>.

Basic CSS Examples

Change the color of a heading using inline CSS:

<h1 style="color:#0D3B66;">Hello World</h1>

Or using internal CSS:

<style>
h1 {
    color: #0D3B66;
    font-family: Arial, sans-serif;
}
</style>
<h1>Hello World</h1>

Common CSS Properties

  • color – Text color
  • background-color – Element background color
  • font-size – Size of text
  • font-family – Type of font
  • margin – Space outside an element
  • padding – Space inside an element
  • border – Border around an element
  • width, height – Size of element
  • display – Block, inline, inline-block, none
  • text-align – Left, center, right, justify

CSS Example: Button Styling

button {
    background-color: #0D3B66;
    color: white;
    padding: 10px 20px;
    border: none;
    border-radius: 5px;
    cursor: pointer;
}
button:hover {
    background-color: #084a8f;
}
