Lecture 6: CSS Box Model & Layout

CSS Box Model

Every HTML element is a rectangular box. The CSS Box Model describes the layout and spacing of these boxes. It has four parts:

  • Content – The actual content of the element (text, image, etc.)
  • Padding – Space between content and border
  • Border – Surrounds the padding (visible line)
  • Margin – Space outside the border, separating elements

Box Model Example

Content inside box

CSS to style a box:

div {
  width: 200px;
  padding: 15px;
  border: 5px solid #0D3B66;
  margin: 20px;
}

CSS Layout

CSS provides several methods to position elements on a page:

  • Normal Flow – Elements are stacked vertically or horizontally as per HTML structure.
  • Float – Moves elements left or right allowing text or inline elements to wrap.
  • Positioning – static, relative, absolute, fixed, sticky
  • Flexbox – Modern layout method for aligning elements in rows or columns.
  • Grid – Two-dimensional layout system for complex designs.
