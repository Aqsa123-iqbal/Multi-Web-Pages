Lecture 5: CSS Selectors

What are CSS Selectors?

CSS selectors are patterns used to select HTML elements you want to style. Using selectors, you can target specific elements, classes, ids, or attributes to apply CSS rules.

Types of CSS Selectors

  • Universal Selector (*) – Selects all elements.
    * { margin:0; padding:0; }
  • Type Selector – Selects all elements of a specific type/tag.
    p { color: #0D3B66; }
  • Class Selector – Selects all elements with a specific class.
    .example-box { border: 1px solid #0D3B66; }
  • ID Selector – Selects an element with a specific id.
    #main-header { font-size: 24px; }
  • Group Selector – Apply same style to multiple elements.
    h1, h2, h3 { color: #0D3B66; }
  • Attribute Selector – Select elements based on attributes.
    a[href] { text-decoration: none; }
  • Pseudo-class Selector – Select elements in a special state.
    a:hover { color: #084a8f; }
  • Descendant Selector – Select elements inside another element.
    div p { color: #0D3B66; }
