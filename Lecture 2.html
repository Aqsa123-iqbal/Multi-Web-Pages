Lecture 2: HTML Basics

Introduction to HTML structure and elements

What is HTML?

HTML stands for HyperText Markup Language. It is the standard language used to create and structure web pages. HTML describes the structure of a webpage using tags. These tags tell the browser how to display text, images, and other content.

Basic HTML Elements

  • Headings – Used to define titles (h1 to h6)
  • Paragraphs – Used to write text content
  • Links – Used to connect one page to another
  • Images – Used to display pictures
  • Lists – Used to organize information

Example of HTML Tags

Some commonly used HTML tags include:

  • <h1> to <h6> – Headings
  • <p> – Paragraph
  • <a> – Link
  • <img> – Image
  • <ul> and <li> – Lists

HTML Logo

Conclusion

HTML is the foundation of all websites. It provides the structure of a webpage, while CSS is used for styling and JavaScript is used to add interactivity. Learning HTML is the first step toward becoming a web developer.
