Lecture 7: Responsive Web Design

What is Responsive Web Design?

Responsive Web Design (RWD) is a technique to make websites look good and usable on all devices – desktops, tablets, and smartphones. The layout and content automatically adjust to the screen size and resolution.

Why Responsive Design is Important?

  • Improves user experience on all devices
  • Reduces bounce rate on mobile devices
  • Essential for SEO – Google prefers mobile-friendly sites
  • Reduces development effort by maintaining a single website for all devices

Techniques for Responsive Design

  • Fluid Grids – Layouts use percentages instead of fixed pixels.
  • Flexible Images – Images resize automatically using max-width:100%.
  • Media Queries – CSS rules that apply only on specific screen sizes.
  • Viewport Meta Tag – Ensures proper scaling on mobile devices.

CSS used for responsive flexbox: 

.responsive-box {
  display: flex;
  gap:10px;
  flex-wrap: wrap;
}
.responsive-box div {
  flex: 1 1 200px;
  background:#0D3B66;
  color:white;
  padding:20px;
  text-align:center;
}

Media Query Example

Change background color on smaller screens:

@media (max-width: 600px) {
  body {
    background-color: #dce6f2;
  }
}
